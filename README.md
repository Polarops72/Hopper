# Hopper
Hopper is a small flying stabilized vehicle made for test purposes

I'm currently working on it, i will publish a release once i finish building and testing it, i'm waiting for some parts and as soon as calibration is going to be done i'm going to make a test flight.

Not everything is perfect and it will not be perfect in the end, because as i said it is just a test vehicle to experiment with TVC mounts, for a TVC Amateur rocket build, maybe it will be published on GitHub one day.
